# MC加工 工具使用履歴・寿命管理システム (ver 1.0.0)

開発品（T形状）のMC加工において使用する3本の工具について、日々の加工数累計と工具交換時の寿命データを自動蓄積・追跡（トレーサビリティ）するためのGoogle Apps Script（GAS）システムです。

## 概要・目的
- **入力の省力化**: 作業員は日々の加工数を入力するだけで、3本の工具の累計加工数を自動更新します。
- **寿命データの蓄積**: 工具交換時に累計をリセットし、「何個加工して交換されたか」の履歴を残します。
- **不良ロスの削減**: 高価な材料のロスを防ぐため、蓄積データから工具の交換基準（限界加工数）を導き出します。

## 構成シート
1. **手順書**: 操作マニュアル
2. **メイン**: 日々の加工数入力および工具交換の実行画面
3. **加工ログ**: 日々の加工記録および工具ごとの累計データ蓄積
4. **交換履歴**: 工具ごとの交換日時、旧Lot、最終加工数（寿命）の記録
5. **グラフ(傾向分析)**: 工具寿命の傾向可視化用ダッシュボード

## 主要な関数 (Code.gs)
- `setupSystem()`: 初期シート構成および入力フォームの自動生成
- `recordProduction()`: 今日の加工数を加算し、加工ログへ記録
- `replaceTool()`: 指定工具の累計をリセットし、交換履歴へ最終累計を記録
- `addInstructionAndCharts()`: 手順書およびグラフ用シートの追加生成
